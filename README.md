# Foundational Cryo-IP Suite

An open-source analog and mixed-signal IP suite for the [IEEE SSCS PICO Chipathon 2026](https://github.com/sscs-ose/sscs-chipathon-2026/).

---

## Overview

This project develops a suite of reusable, foundational analog and mixed-signal IP macros in the GF180MCU PDK, targeting Track A of the Chipathon.

To validate their interoperability, the blocks are integrated into a system-level application: an on-chip deep-cryogenic temperature sensor for Transmon qubits.

The repository is in its early stages as we prepare for the design phase. We will be updating this README regularly as work progresses on schematics, layout, and cryogenic simulations.
